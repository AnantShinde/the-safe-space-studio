# Image Prompts for The Safe Space Studio

How this works:
1. Generate each image with the prompt below (Google **Imagen** in AI Studio/Gemini, **ChatGPT/DALL·E**, or **Meta AI** at meta.ai — all have free tiers).
2. Save the result into the `images/` folder using the **exact filename** listed.
3. That's it — the site already points at these filenames and will switch from the placeholder to your real image automatically. No code changes needed.

**Shared style (paste into every prompt for a consistent look):**
> Soft, warm, modern flat illustration with gentle watercolor texture. Calming, hopeful, emotionally honest. Color palette: sage green (#9CAF88), warm cream (#F5F3ED), soft blush pink (#F4E8E8), muted slate blue (#5B7A9E). Inclusive and diverse, gender- and culture-neutral where possible. No text, no logos, no watermarks. Tender and dignified, never clinical or stocky.

**Negative prompt (where supported):** text, words, watermark, logo, deformed hands, extra fingers, harsh lighting, medical/graphic imagery, clip-art, oversaturated colors.

### Tips
- **Aspect ratio matters** — match the ratios above so images aren't awkwardly cropped (the journey cards crop to a wide band; portraits stay tall).
- Generate 3–4 variations of each and pick the warmest, least "stocky" one.
- Keep file sizes reasonable (under ~500 KB each) — export as JPG for photos/illustrations.
- Want different filenames or a different framing? Tell me and I'll rewire the site.

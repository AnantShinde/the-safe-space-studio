# The Safe Space Studio — Local Site

Local static site for The Safe Space Studio (Ritika Latke). This is an MVP single-page site plus a privacy page.

Preview locally using Python 3 simple HTTP server:

```bash
cd the-safe-space-studio
python3 -m http.server 8000
# open http://localhost:8000 in your browser
```

Or use VS Code Live Server extension.

Files:
- `index.html` — main single-page site
- `privacy.html` — privacy & confidentiality
- `css/` — styles
- `js/` — minimal interactivity
- `images/` — placeholder illustrations
